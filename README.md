# Patito IA

Proyecto web de un agente de IA con estilo pastel, fondo suave, logo de pato y chat interactivo para hablar sobre cómo se siente una persona cada día.

## Características
- Diseño pastel y agradable
- Logo de patito kawaii
- Chat con respuestas emocionales y amistosas
- Botones rápidos para estados de ánimo
- Totalmente funcional en HTML, CSS y JavaScript

## Cómo abrirlo
1. Descarga o clona este repositorio.
2. Abre el archivo `index.html` en tu navegador.
3. ¡Listo!

## Tecnologías usadas
- HTML
- CSS
- JavaScript
